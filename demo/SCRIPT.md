# Demo video script (4 min 55 s)

**Short, simple version for a relaxed speaking pace.**

- Each line uses only about half of its time slot, so there's room to breathe and you won't fall behind.
- Start each line when the time comes up, or when you see the action happen on screen.
- If you finish early, a short pause is fine; the video keeps showing the action.
- You don't need to read out any numbers. The screen shows them.

| Time | On screen | Say |
| --- | --- | --- |
| **0:00** | Simulator page | Hi! This is **Hive Lab**, a simple website that teaches the **Artificial Bee Colony algorithm**, one step at a time. |
| **0:22** | Learn page | The **Learn** page explains the basics. Flowers are possible answers, bees search for the best flower, and these are the main formulas. |
| **0:45** | "Slide example" is clicked | Now let's try the **example from our slides**. |
| **0:53** | Step, then "Show the math" | Each **Step** is one bee's move. **Show the math** gives the full calculation. |
| **1:08** | A red ✗ on the map | If the new spot is worse, the bee **stays**. |
| **1:18** | Bee dancing at the hive | Next, the bees **share** their results. Better flowers get a **higher chance** of being picked. |
| **1:31** | A blue bee flies to a flower | An **onlooker** bee uses that chance to pick a flower. |
| **1:42** | A pink bee flies away | If a flower stops improving for too long, it's **dropped**, and a **scout** bee finds a new one. |
| **1:58** | Table changes to matrices | This view shows the **same tables as the slides**. |
| **2:10** | Slide Check page | The **Slide Check** page tests the tool against the slides. **Every hand-calculated value matches**, and it even spots small mistakes on the slides. |
| **2:36** | Free run, picking a problem | In **Free run**, I can pick any problem and change the number of bees, the limit, and the cycles. |
| **2:52** | Play is pressed | When I press **Play**, the whole colony works **on its own**. |
| **3:06** | Progress chart | This chart shows the answer **getting better** over time. |
| **3:17** | Roulette wheel | This wheel shows how onlookers choose. **Better flowers get bigger slices**, so more bees go there. |
| **3:40** | "Quiz me" switched on | Now, **quiz mode**. |
| **3:44** | A question appears | Before each move, the tool asks me to **guess what happens next**. |
| **3:58** | Green "Correct" message | It tells me **right away** if I'm right. |
| **4:10** | Race page | Finally, the **Race** page. |
| **4:17** | Race running | The bee colony races against **random guessing**, and both get the same number of tries. |
| **4:33** | "30 of 30" result | Over thirty races, **the bees win every time**. |
| **4:42** | Back to the Simulator | **Thanks for watching!** The links are in the description. |

---

### Tips for recording
- Read it out loud once along with the video before you record.
- Speak calmly. Pauses are fine, but rushing isn't.
- In CapCut, iMovie or Clipchamp, you can drag your voice clip a second earlier or later if a line doesn't line up.
